# 상용 서비스 계획 — 동네한권 (단독 마스터 예비본: M1 + M2 전 범위 통합)

> **문서 성격**: 단독 마스터 예비본(`choise-hun/libtalk`)의 전체 범위(M1 + M2 + C-46·C-47 개정 사항 전부 포함) 및 **Step별 분리 커밋 로드맵**의 기준 문서다.
> **참조 문서**: 제품 동작·수용 기준은 [02 요구사항 정의서](../개발산출물/02_요구사항_정의서.md), DB 스키마는 [05 ERD 및 DB 설계서](../개발산출물/05_ERD_및_DB설계서.md), API 명세는 [06 기능·API 정의서](../개발산출물/06_기능_API_정의서.md), 디자인 토큰은 [디자인 기준](../개발산출물/디자인_기준.md) 및 [DESIGN.md](../DESIGN.md)를 따른다.
> **역이식(Cherry-pick) 호환 원칙**: 본 협업 레포(`axteamc/localone`)에서 특정 주니어가 불참하거나 미달할 경우 해당 기능만 떼어 이식할 수 있도록, M1의 Feature·Step ID(`AUTH`, `LIB`, `VISIT`, `LOCAL`, `LOAN`)와 테이블/API 경로를 100% 동일하게 유지하고 **커밋을 Step 단위로 분리해 쌓는다.**

## 1. 프로젝트 개요와 목표

- **서비스명**: **동네한권 (localone / libtalk)**
- **핵심 가치**: 시각화된 지역 도서관을 앱에서 **"방문"**하는 느낌으로 만나는 지역 소규모 독서 커뮤니티.
  1. **방문(`VISIT`)**: 데포르메된 미니멀 지도에서 주변 도서관을 골라 들어가면 도서관 고유 룩(4종: `warm`, `toffee`, `oxford`, `modern`)과 방문 멘트 카드·다녀왔어요 스탬프·방명록·오늘의 서가(책장)를 만난다.
  2. **광장(`LOCAL`)**: 그 도서관의 2열 메이슨리(핀터레스트형) 피드에서 이웃의 독서 기록·사진·방명록·모임을 훑고, 상세에서 같은 책 이어 읽기·대여(우선)·구매(예스24)로 이어진다.
  3. **기록·모임(`READ`·`CLUB`)**: 내 독서 기록과 도서관별 발자취를 남기고 템플릿으로 꾸며 광장에 올리며, 도서관 기반 소규모 독서 모임(댓글 일정 협의·참가·출석·후기·다음 회차 생성)에 참여한다.
  4. **도서 탐색·반납 비서(`LIB`·`LOAN`, 보조)**: 도서 검색(테마/인기 추천·최근 본 책)과 주변(3km/5km)·도시 전체 소장/대출 가능 조회(`어제 기준` 3상태 + 실시간 확인 딥링크)를 거쳐, `"빌릴 예정"` → `"빌렸어요"`(D-day 타이머 + D-3·D-1·당일 기기 알림) → `"반납했어요"`(동의 시 도서관 반납 집계 반영)로 순환한다.
  5. **프로필·소셜·알림함(`USR`, C-46·C-47 통합)**: 내 정보 3탭(`내 게시물 / 좋아요 / 북마크`), 이웃 팔로우, 홈·내 정보의 앱 내 알림함을 제공한다.
